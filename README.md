# Felix Lotionstein's Unofficial Creatures and Beasts Port

This is a fork of the Creatures and Beasts by joosh_7889 and HellionGames

This project is to serve as a temporary port of Creatures and Beasts to 1.20.1 while the original authors make plans to port it themselves.

Original Repository: https://github.com/bonsaistudi0s/Creatures_And_Beasts-Forge

Original CurseForge Page: https://www.curseforge.com/minecraft/mc-mods/creatures-and-beasts

## Changes
- Updated nearly all classes and .json files to Forge 47.3.0, providing Minecraft 1.20.1 compatibility.
- Migrated all Entity, Armor, Renderer, and Model classes from Geckolib 3.x to 4.x.
